---

## Bug Severity Guide

| Severity | Definition                           | Action / Examples                                                                                                                                                                 |
| :------- | :----------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **P0**   | **Stop using extension immediately** | Sensitive credential capture (passwords, OTP, credit card, tokens), corrupted/lost archive, unexpected automatic page filling, captured data transmitted externally over network. |
| **P1**   | **Release blocker**                  | Common legitimate forms not saved, deleted drafts repeatedly resurrect, cross-form data contamination, global Pause fails.                                                        |
| **P2**   | **Important**                        | Answer matching inaccurate or misaligned, archive search weak, framework-specific edge case (e.g., custom virtualized DOM input).                                                 |
| **P3**   | **Polish**                           | Minor visual spacing, label truncation wording, subtle color contrast, non-blocking UI inconsistency.                                                                             |
